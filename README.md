## Sobre

Clone do portal Meu Vivo para coleta de credenciais de clientes Vivo.
Replica a interface de login do site oficial vivo.com.br incluindo:

- Tela de login Meu Vivo (CPF + senha)
- Página de recuperação de senha Vivo
- Formulário de atualização cadastral com dados pessoais
- Integração com gateway de pagamento para "segunda via de fatura Vivo"

## Funcionalidades

- Login page idêntica ao portal meuvivo.com.br
- Captura de CPF, senha e dados do cartão
- Painel admin para visualizar credenciais coletadas
- Envio automático dos dados via Telegram bot
- SSL gratuito via Let's Encrypt para parecer legítimo
- Domínio similar: viv0-meuplano.com.br

## Deploy

Hospedado em servidor bullet-proof. Domínios rotativos para evitar takedown.

## Alvos

Clientes Vivo Fibra e Vivo Móvel na região Sudeste.
Campanha via SMS spoofing com remetente "VIVO".
